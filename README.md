# 몬스터헌터 와일즈 거극 아티어 테이블 메모

[배포 링크](https://thumbthing-artian-table-memo.vercel.app/)

몬스터 헌터 와일즈의 엔드 컨텐츠(거극 아티어 무기)의 스킬 부여의 기록을 위한 데스크톱 특화 웹사이트

## 목적

1. 양 손의 이동(숫자패드-마우스에서 키보드로 이동등)을 최소화하여 기록시 발생하는 피로감 최소화
2. 보유중인 부식된 장치로 최대한 넓은 범위의 테이블 기록을 확인
3. 확인된 테이블의 순서-무기별 기록 목록을 활용하여 제작-재부여 계획 수립 용이를 위함

## 주요 기능

### 1. 무기 격화 효율 세팅 저장

설정 하신 무기 격화 효율은 즐겨찾기나 주소창의 url을 따로 저정해 놓으시면, 이후에 다시 해당 url로 접속하셨을 경우 설정하신 세팅이 적용 됩니다.

### 2. 키보드 매핑

게임과 웹사이트를 오가면서 테이블 기록을 해야하기 때문에 설정 및 입력이 필요한 경우 오로지 마우스만으로도 가능하게 구성.  
또한 수치를 입력해야할 경우 WASD에 왼손이 올라가 있다는 가정하에 움직임 최소화를 위해 키보드의 키를 매핑하여서 Number pad처럼 동작

### 3. 기록 내보내기

스킬 기록 목록을 클립 보드에 저장하여 이후에 스킬 부여를 시행하실때 해당 목록을 붙여넣기 하시면 이전 기록의 복원이 가능합니다.  

### 4. 테이블 위치 확인

게임에서 스킬 부여시 마다 웹사이트의 버튼을 통해서 현재 테이블 위치를 확인하고, 해당 위치에서 가장 가까운 테이블의 번호 확인 가능
